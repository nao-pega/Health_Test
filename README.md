# Health_Test

## 概要
Health_Testは、日々の健康管理をサポートするためのシンプルなWebアプリケーションです。  
ユーザーが自分の健康データを入力・記録し、視覚的に管理できることを目指しています。

## 主な機能
- 健康データ（体重、体温、血圧など）の登録と編集  
- 登録データの一覧表示  
- データの視覚化（グラフ表示など、今後対応予定）  

## 使用技術
- Python 
- Flask (Webフレームワーク)  
- HTML/CSS/Java Script（フロントエンド）
