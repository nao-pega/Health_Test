# Health_Test

## 概要
ユーザーの健康状態をチェックし、その結果に基づいてパーソナライズされた
健康管理アドバイスと機能を提供するWebアプリケーションです。
DBは使用してないのでデータの記録や保持はできません。

## 主な機能
1.ログイン
ユーザー名とパスワードによるログイン・新規登録機能を提供します。
新規ユーザー（または初回ログイン時）は、必須の健康状態チェックに誘導されます。

2.健康状態チェック (Health Questions)
睡眠、運動、食事、ストレスなど7つの質問に回答することで、現在の健康スコア（100点満点に換算）を算出します。
スコアに応じて、「Healthy」「No Problem」「Attention Needed」の3段階に分類され、結果に応じた具体的な生活アドバイスページへリダイレクトされます。

3.パーソナルヘルスプラン
健康スコアの月別推移グラフを表示するダッシュボード機能です。
ユーザーのデータに基づいた最適な運動プラン、栄養アドバイス（旬の食材、おすすめレシピ）、および健康改善のための具体的な改善提案を提供します。

4.AI食事分析(未実装)
写真から食事内容を分析する機能です（ヘッダーメニューに項目あり）。

5.3分ヨガ・ストレッチ
手軽にできるヨガやストレッチに関する情報を提供するページです。

6.健康クイズ
健康に関する知識を試すクイズ機能です。

7.フードレシピ 
地中海式食生活、ビーガン食、低炭水化物ダイエットなど、様々な健康的な食生活に関する詳細な情報を提供します。

## 使用技術
